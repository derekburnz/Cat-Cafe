## Nits

**N35 (nit, for the RenameCat build) Send the display name, not the saved one.** `CatStats.view` (`CatStats.luau:233`) copies `instance.name` into `CatView`, which reaches the owner through ProfileSync. Today nothing sets a name. When RenameCat lands, the view should carry the same filtered string as `DisplayName`, not the raw saved text. Then the client never holds unfiltered text, and a name saved under an older filter shows under today's.

**N36 (nit) `sanitizeName` cuts by bytes.** `string.sub(name, 1, 200)` (`ProfileSchema.luau:177`) can split a multi-byte character, leaving invalid UTF-8 that the display filter may reject. RenameCat caps names at 20 characters, so a real save never reaches 200 bytes. Returning nil when `utf8.len(name)` is nil or the name is too long keeps a damaged save from carrying bad text.
