## Bugs

### [blocker] shared/Types.luau returns nil, so no shared module can be required  (found by: unit specs)
Owner: engineer
Repro: 1. `cd games/cat-cafe/tools/cloudcheck && npm test`  2. Catalog.spec, Catching.spec, Economy.spec fail to load.
Expected: `require(ReplicatedStorage.Shared.Types)` returns a value.
Actual: `Module code did not return exactly one value: ReplicatedStorage.Shared.Types`. Roblox raises the same error for a ModuleScript whose return is nil, so Catalog, Catching, Economy, Remotes and every server service would fail at startup.
Evidence: run-tests output, `src/shared/Types.luau` last line `return nil`.
Notes: `return {}` is the usual fix for type-only modules.
