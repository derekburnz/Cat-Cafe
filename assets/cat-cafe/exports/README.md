# Exports

Generated by `../blender/build_all.py`. Do not edit by hand; edit the generator and rebuild.

- `<Name>.fbx`: the asset, Y up, front -Z, 1 unit = 1 stud, palette texture embedded. Import this into Studio.
- `<Name>.glb`: the same asset as glTF for viewers and other tools.
- `CatCafe_Palette.png`: the single 256 x 256 texture every mesh uses. Upload once.
- `manifest.json`: every asset with triangle count, size in studs, pivot rule, sit point for spots, head and tail joint offsets for cats, and Studio notes (which parts get Neon or Transparency). The engineer can size placeholder Parts straight from `size_studs`.
