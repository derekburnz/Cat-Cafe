# Cat Cafe Blender generators

Owner: asset-artist (see CLAUDE.md). Read the asset-pipeline skill and `docs/art/style-guide.md` before adding files.

Every model in `assets/cat-cafe/exports/` is generated by the Python in this folder. Nothing is hand-modeled, so a style change (a new palette, a chunkier bevel, a bigger head) is a code edit and a rebuild, and every asset stays consistent. The scripts only use `bpy` and `bmesh`, so they run in Blender's GUI, in Blender headless, or with the `bpy` pip module without Blender installed.

## Files

| file | what |
|---|---|
| `palette.py` | the 64 swatches (mirrors style guide section 2) and the palette PNG writer |
| `common.py` | `Builder` (box, cylinder, sphere, pyramid, wedge, ring primitives tagged with a swatch), chamfer, UV to swatch center, FBX and GLB export, Cycles preview renderer |
| `cats.py` | the one cat rig and the 12-cat `ROSTER` (data-model.md section 3). Body, Head and Tail are separate objects |
| `npc.py` | customers A (adult), B (kid), C (elder) |
| `furniture.py` | counter, espresso machine L1 to L3, the five cat spots with `SIT_POINTS`, round table, chair |
| `decor.py` | window plants, rug, neon sign, fish tank, hanging lamp, plant pot, menu board, cup, Open/Closed door sign, string lights |
| `alley.py` | dumpster, trash can, street lamp, crate, cardboard box, pallet, puddle, rescue props (stuck tree, stuck box, drainpipe), shop window |
| `park.py` | bench, tree, fountain, gate |
| `items.py` | food bowls, kibble, tuna can, salmon, net L1 to L3 |
| `accessories.py` | glasses, bow tie, apron, hat and the `ATTACH` table of attachment points |
| `poses.py` | poses as Body CFrame plus Head and Tail angles: upright, carried, and the stuck pose per rescue prop; renders the pose previews |
| `scenes.py` | the cafe, alley and night alley vignettes rendered to `docs/concepts/cat-cafe/` |
| `contact_sheet.py` | tiles the previews into sheets |
| `gates.py` | per-asset PASS/FAIL checks (budget, transforms, one palette material, UVs on swatch centers, naming) and WARN checks (pivot, centered footprint); writes `exports/gates.md` |
| `build_all.py` | runs everything and writes `exports/manifest.json` and `exports/gates.md` |

## Run it

On Derek's PC with Blender installed (4.2 or newer; written against 5.2):

```powershell
# Windows PowerShell, from the repo root. Headless build, exports, previews and vignettes.
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b -P assets\cat-cafe\blender\build_all.py -- --render --scenes
```

Without Blender, using the pip module (about 1 GB download, needs Python 3.11 to 3.13):

```bash
python -m venv .venv-bpy && .venv-bpy/bin/pip install bpy
.venv-bpy/bin/python assets/cat-cafe/blender/build_all.py --render --scenes
```

Inside the Blender GUI: Scripting workspace, open `build_all.py`, add `--no-reset --no-export` to the argument handling or just run it. Objects appear at the origin with the palette material, which is the fastest way to eyeball one asset: run with `--only Tabby`.

Flags: `--only Tabby,Counter` (name fragments), `--render` (one Cycles preview plus a five-view sheet per asset), `--no-views` (skip the sheets), `--views-engine workbench|cycles` (sheet renderer; the default `auto` uses Workbench where a GPU context exists and Cycles CPU otherwise), `--scenes` (two vignettes), `--no-export`, `--samples 64`, `--out DIR`, `--docs DIR`.

The build runs every asset through `gates.py` and prints one line per asset. FAIL checks (budget, transforms, material, uv, naming) make the build exit non-zero; WARN checks (pivot, centered) do not. `exports/gates.md` has the table and the reasons. With `--render`, `docs/concepts/cat-cafe/views/<Name>.png` shows front, left, back, top and three-quarter views side by side, textured with the palette and without the floor, which is the fastest way to catch a wrong pivot, a mirrored detail or a swatch mistake. The sheets use Workbench in Blender or the `bpy` module on Windows and macOS; the `bpy` module on Linux without libEGL (a cloud container) would abort on Workbench, so there the build switches to Cycles CPU at 16 samples (about 8 s per asset) and composites the tiles over the sheet colour. Both ideas come from [ozanzeng/blender-LPM-skill](https://github.com/ozanzeng/blender-LPM-skill).

## Studio import

See style guide section 10. Short version: 3D Importer, Scale Unit Studs, drop the `.fbx`. Multi-object assets (cats, neon sign, fish tank, street lamp, hanging lamp, fountain, gate) come in as a Model with one MeshPart per object; single-object assets come in as a MeshPart. Upload `CatCafe_Palette.png` once as an image asset and set it as the texture if the importer did not embed it. Save the imported model as `assets/cat-cafe/rbx/<Name>.rbxm` and drop a copy into `ReplicatedStorage.Assets` for the engineer.

## Editing rules

- Change colors in `palette.py` and the style guide together. Never hard-code a hex in a model file.
- Keep every primitive on the 0.25 stud grid where it touches the floor or a wall.
- New asset: add a `build_<thing>(mat)` that returns a list of objects and register it in that module's `ASSETS` with a triangle budget. Names follow `CatCafe_<Category>_<Name>`.
- Multi-object assets exist only when Studio needs separate parts (a Neon bulb, transparent glass, a moving gate leaf, a cat head). Otherwise one object, one MeshPart.
- Do not add a rig or animation here yet. Cat motion in the slice is CFrame tweens on Head and Tail (features.md priority 11).
