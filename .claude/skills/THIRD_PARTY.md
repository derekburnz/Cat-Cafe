# Third-party skills in this folder

Copied on 2026-10-26 from the repositories below after Derek's go-ahead (thread "Find Roblox dev skills and tools"; ranking and reasons in `docs/tooling/skills-and-tools-survey.md`). Every copy keeps the upstream `LICENSE` (all MIT). Rules:

- Do not edit a copied skill in place. To update, re-copy the folder from upstream at a new commit, read its `SKILL.md` again, and change the commit column here.
- A skill is instructions the agent follows, so read a new upstream version before copying it. None of the versions below run installers, phone home, or touch files outside the project without asking; the scripts that upload (`blender-to-roblox/scripts/upload-asset.sh`) or install (`roblox-doctor --fix`) ask first and read keys only from environment variables.
- Skills are Markdown plus optional scripts, so they work in Claude Code on the PC and in cloud threads. Scripts that need Blender, Studio, Lune or `uvx` only run on the PC.
- Each skill's description sits in every agent's context. Add more only when a role needs them; prefer copying one folder over a whole pack.
