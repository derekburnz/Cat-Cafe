# Area pictures

Card pictures for the F84 cannon picker and the Areas screen, 512 x 256 PNG each. UI-Engineer cropped them from Model-Agent's own area renders; no Roblox characters appear in them. Tools-Agent uploaded them to Roblox as images with `upload-image.yml`; each id is listed below and in the UI code that draws them. Each upload makes a new asset, so upload a changed file once and update its row.
