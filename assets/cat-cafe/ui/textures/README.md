# UI textures

Original images for the UI, uploaded to Roblox as images and referenced from `Theme.textures` in `games/cat-cafe/src/client/UI/Theme.luau`. An empty id there means the image is not uploaded yet, and the UI draws without it.

| file | use | Theme key |
|---|---|---|
| `UI_ButtonTiles.png` | 64 x 64 tile with one rounded L-shaped mark, black on transparent. Buttons tile it every 18 px at 90% transparency over their fill, like the faint tile marks on popular simulators' buttons. | `buttonTiles` |
