## 2. How a candidate was judged

The pipeline that exists today: every 3D asset is generated by Python in `assets/cat-cafe/blender/` (one palette texture, swatch UVs, triangle budgets, FBX and GLB export, `manifest.json`), so a Blender tool helps only if it works headless or adds something the generator lacks (visual QA, Roblox import checks). Code lives in files synced by Rojo with a Rokit toolchain and the `check.sh` gate, plus `tools/cloudcheck` for tests in the cloud. Studio is driven by Roblox's built-in MCP server. Cloud threads cannot reach Studio or Blender, so a tool that needs either runs only on Derek's PC. Skills are Markdown, so they work in both places once committed to the repo.

Three risks apply to every item here:

1. A skill is instructions the agent follows. Read each SKILL.md before installing. Clone repos instead of running `curl | bash` or `irm | iex` installers.
2. Every installed skill adds its description to the agent's context on every turn. Cherry-pick skills from the big packs instead of installing 40 at once.
3. MCP servers that take an Open Cloud key: one key per purpose, least permissions, read and write keys separate, stored in environment variables (CLAUDE.md rule 13). Never a `.ROBLOSECURITY` cookie; that is a full account credential.

## 9. UI, audio and animation

UI. The ui-designer works from HTML and SVG mockups to Luau, and nobody designs in Figma yet. If Gavin or a friend does, [xtrair/figma-to-roblox-ui](https://github.com/xtrair/figma-to-roblox-ui) ([DevForum post](https://devforum.roblox.com/t/figma-%E2%86%92-roblox-ui-a-claude-skill-for-pixel-accurate-scale-only-gui-imports/4891173)) is a Claude skill that reads frames through the Figma MCP and emits Scale-only, anchored Luau with a validator, and it checks the output of the import plugins (FigBloxUI, RoImport, Bloxporter). [GuiForge](https://devforum.roblox.com/t/free-guiforge-roblox-ui-editorfigma-export/4834077) is a free browser UI editor with Figma export (registration required). Neither is needed for the slice.

Audio. No tool needed. [Roblox audio assets](https://create.roblox.com/docs/audio/assets): the Creator Store has over 100,000 licensed sound effects and tracks usable on Roblox, unverified accounts can upload 100 audio assets per 30 days (2,000 if ID verified), formats mp3, ogg, wav, flac under 20 MB and 7 minutes, uploads stay private until moderated and can be granted to specific experiences. Order of preference: Creator Store audio, then CC0 packs such as Kenney, uploaded with Asphalt, with a `CREDITS.md` for anything CC-BY. The roblox-dev-kit `find-resources` skill automates the license gate.

Animation. The slice animates cats with CFrame tweens on Head and Tail (features.md priority 11), so nothing now. When cats get rigs: the Roblox Blender plugin uploads rigged meshes, and the community [Blender rig exporter and animation importer](https://devforum.roblox.com/t/blender-rig-exporteranimation-importer/34729) plus the [Motor6D and bone compatible pipeline](https://devforum.roblox.com/t/full-roblox-%E2%86%94-blender-rig-animation-pipeline-motor6d-bone-compatible-ikfk-ikfk-switching/4042154) cover Studio rig to Blender and back. EL4CTEO/blender-skills has rigging and animation skills for that phase.
